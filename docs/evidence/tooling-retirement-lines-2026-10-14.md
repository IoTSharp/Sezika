# T7：独立逐行非执行裁定

退役审查请求可选追加 `ReviewedNonExecutionLines`。每条裁定必须同时绑定完整调用者 SHA、UTF-8 行正文 SHA、准确行号、与调用者类型相符的类别、理由和独立确认。过期、重复、失配、未确认和类别错误均拒绝；报告原样记录裁定。

这允许独立审查明确说明负控字符串、分类规则和来源元数据为何没有执行旧脚本。它不是自动控制流证明，也不能替代迁移能力门或完整调用者范围声明。旧请求继续保持保守结果。

Windows 与 Ubuntu WSL 的 Native AOT 检查均先运行 1 项，再通过完整 16 项。两份原始原生回执、检查输出和准确两源 SHA 见 [验收目录](tooling-retirement-lines-2026-10-14/acceptance.json)。冻结 90 文件的整体集成状态仍是部分通过；本次没有激活仓库实际退役门、删除脚本或宣称迁移整体完成。
