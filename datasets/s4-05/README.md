# S4-05 数据准入示例

状态：`fixture_only`。这里只有本轮编写的 5 条原创审计输入，不是新真实训练、开发、校准或封存测试集。示例没有模型预测、人工标签、准确率或校准结果；文本中的人名、气象站与货架均为虚构实体。中文行是本轮为英文示例编写的翻译，反事实行调换了角色，均保留父记录与同一家族。

`example-manifest.json` 把来源版本和 JSONL 原始字节 SHA-256 固定下来；`example-records.jsonl` 是审计清单，同时作为这组极小原创输入的原始资产。所有人工复核、许可准入仍为 `Pending`，用途 allowlist 为空。`Apache-2.0` 表示拟随仓库分发的原创数据许可表达式，不代表已完成人工许可审签。

这些公开可读记录均标为 `DevelopmentViewed`。名为 `example-test-slot` 的行只展示 `SealedTest` 字段，封存状态为 `Unsealed`，因此审计必须阻止把它当成真正的封存测试。程序应返回阻断状态，不应有人为了得到成功退出码而把示例改成“已批准/已封存”。

字段、约束、固定门槛、未来获准后的运行方法和限制见 [S4-05 数据隔离说明](../../docs/data-isolation-s4-05.md)。路线图阶段状态只在 [ROADMAP](../../ROADMAP.md) 维护。
